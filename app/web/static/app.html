萬能字幕產生器

上傳影片或音檔,自動產生字幕並翻譯。登入後只看得到自己的檔案與字幕。

使用 Google 帳號登入

這台伺服器還沒有設定 Google 登入(管理者執行「設定Google登入.bat」後就會出現)。

開發用登入

換一個名稱登入就是另一個使用者。正式上線前會關閉這個功能。

      詞彙表只有你自己用
      
      
      一行一個詞。寫成「原詞=譯詞」時,翻譯會固定使用這個譯法;只寫原詞則用來提高轉錄辨識率。# 開頭的行是註解。例:熱軋=hot rolling
      
      
      
      
      
    
      

    
      
      
      API 翻譯金鑰
      
      
      用你自己的金鑰翻譯,費用由你的帳號負擔。金鑰加密後存在伺服器,只在你的翻譯工作進行時使用;這裡只顯示末四碼,別人(包括管理者)看不到。不用 API 翻譯的話可以不填,離線翻譯(M2M100)不需要金鑰。
      
      
      你的帳號沒有開通 API 翻譯,需要的話請聯絡管理者。
