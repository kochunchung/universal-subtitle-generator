網頁版第 0 階段:瀏覽器抽音訊與大檔上傳實測

目的:確認「一般會員在瀏覽器先抽音訊再上傳」與「付費會員分塊上傳大影片」這兩條路在你的電腦上行不行。 影片只會傳到你這台電腦上的測試伺服器(127.0.0.1),測完立刻刪除,不會離開你的電腦。

1. 選一個影片

把影片拖到這裡,或
尚未選擇檔案。建議用 Teams.mp4(約 4 GB)測一次,再用一個小檔案測一次。
這個瀏覽器的環境

2. 測試 A:瀏覽器抽音訊(一般會員路線)

用 ffmpeg.wasm 在瀏覽器內抽出單聲道 MP3,不把整支影片讀進記憶體。第一次會下載約 32 MB 的元件(之後有快取)。 測試中請按 Shift+Esc 開 Chrome 的「工作管理員」,看這個分頁的「記憶體使用量」最高到多少,測完告訴我。

等待選檔。
ffmpeg 訊息

  


  

    
3. 測試 B:分塊上傳原始影片(付費會員路線)

    
每塊 16 MB 依序上傳到本機測試伺服器。傳到一半可按「模擬斷線」,再按「續傳」,確認會從伺服器已收到的位置接著傳。
      傳完後伺服器會用現有程式的 ffprobe 與 extract_mp3 處理並量時間,然後刪除檔案。

    

      
      
      
    

    

    
等待選檔。

    

  


  

    
4. 測試 C:伺服器端上限檢查

    
模擬「一般會員」身分上傳選到的檔案。若檔案超過 200 MB 或不是音訊檔,伺服器應在一開始就拒絕。

    

    

  


  

    
5. 結果報告

    
測完後按「複製」,整段貼回給我就好。
